# 路线图 / Roadmap

本文件是**唯一**集中记录"做了什么、正在做什么、想做什么、已经否决什么"的地方。
`docs/CHANGELOG.md` 只写每个版本对用户可见的变化；易变状态（CI run、串口、验收清单）在
`docs/HANDOFF.local.md`（不入库）。

**维护规则**：每次发布新版本，必须在本文件「已发布」里追加一行（批次 + 版本 + 一句话），
并在 `docs/CHANGELOG.md` 记用户可见变化。两者缺一不算发布完成。

This is the single place for shipped / in-flight / planned / rejected work. `docs/CHANGELOG.md`
covers user-visible changes per release; volatile state lives in the untracked
`docs/HANDOFF.local.md`. **Rule: every release appends one row here and one entry in the changelog.**

## 已否决 / Rejected

- **"附着式启动"（进传书页不碰网络）**：收益小、风险大（组件掌管 netif/WiFi/httpd/事件循环）。用户 2026-10-27 决定不做。
- **横屏主页**：无意义，主页/书架保持竖屏。
- **锁屏预览继续区分横竖**：两槽位本质是两套图。
- **远程监看口令短于 4 位**：保留 32 位一次性 token，四位密码是可选的弱路径。
